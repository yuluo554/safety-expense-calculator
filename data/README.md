# data/ 数据台账

> 规则（ai-tool-project-sprint 阶段 1）：每份数据登记来源与许可；规范条目挂出处 + status（`verified`/`pending`）；程序化自制带真值数据是核心资产（固定输入可复现）。`_private/` 目录不入仓。
> 纪律：**未挂原文核对不得落库/生效/进入计算路径**；搜索摘要一律不采信，数值以官方原文直连核对。

## 四、合成数据纪律

- **假企业与假身份白名单**：合成企业统一使用虚构名称（如"示例建设工程（合成）有限公司"）＋虚构统一社会信用代码（保留测试号段 `90000000…SYN`）；不得使用任何真实企业名称、产能、营业收入或台账数据。
- **禁止真实号段**：不使用任何真实统一社会信用代码、真实企业名称、真实会计科目台账。
- **植入真值**：真值库由 `tools/gen_synthetic.py` 生成时同时产出**期望计提金额与期望合规结论**；期望金额走**独立计算路径**（生成器只用规则包 JSON 原始数值做一次性公式演算，不调 safefee 引擎），基准层用引擎全量重算对账（双重记账防"真值抄引擎"）。
- **算例覆盖三类计提机制**：按产量（煤炭四变体）、按营业收入超额累退（危险品全分段 + 电力生产/供应两套标准）、按工程造价比例（建设工程三类别）各设算例，含**恰好等于分段点 ±0.01 邻域**的边界档案与单位口径错配（元/万元）档案。
- **误报对照集**：`data/truth/negatives/` 显式声明"应零命中"的干净档案（3 份）与"应降级"的档案（CNY10k/CNY100m 可定义性换算 → 只报 warning，2 份）；基准层只读该声明，不自行挑选对照档案。
- **双版本对照真值**：同一计提对象（煤炭突出/高瓦斯、危险品、矿山工程）分别按 136 号与 2012 版规则生成两套期望值，全部由规则包数值独立算出，用于验证版本切换不改口径。
- 生成器为**唯一写入者**：产物禁手改；再生成须逐字节一致（守门测试）。
