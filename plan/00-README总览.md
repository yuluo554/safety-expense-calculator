# 10-14-safety-expense-calculator 项目计划总览

**项目**：企业安全生产费用提取与使用合规计算工作台（高危行业财务合规工具，Windows 桌面 + CLI 双形态，十二行业计提引擎 + 超额累退分段 + 双版本规则集 + 台账对账 + 报告导出）
**方法论**：ai-tool-project-sprint（条款库 + 版本化计提规则集 + 合成台账真值基准 + 证据指纹 + 离线交付）
**项目系列**：同系列第 17 题（前作名称与业务领域按脱敏纪律不入公开仓，见「决策记录」品牌隔离项）
**命名约定**：本地目录 `10-14-safety-expense-calculator`（`10-14`=2026-10-14 日期标签）；**GitHub 仓库名 = `safety-expense-calculator`（纯净名，去日期前缀）**，沿用系列惯例 `yuluo554/<kebab-name>`；署名 `yuluo554`（LICENSE/pyproject 一致）。
**定位宣言（v1）**：把"按什么标准提 → 提多少（分段怎么算） → 这笔支出算不算合规 → 去年提够没有"整条链做成**规则化、可复现、逐笔挂条款依据**的本地工作台——LLM 聊天给不了持久规则包、超额累退的逐段可溯计算与全量边界枚举，本工具是安全生产费用计提与专项审计前的口径防线。
