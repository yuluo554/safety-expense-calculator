### 1.2 规则入库流程（M1，逐条）

对每条计提标准：

1. **定位**：办法第 X 条（从 `.docx` 解析出的条文定位，**不采信搜索摘要**）；
2. **核对**：直连 gov.cn 原文/附件，逐字比对数值与适用条件；
3. **落库**：在生成器源数据里写入 `value` / `rate` / 适用条件 + `provenance`（文号/条款/URL/抓取日期/sha256）；
4. **置状态**：核对通过 → `status: verified`；未核对 → 保持 `pending`（`value: null`）；
5. **重生成**：`tools/gen_rulesets.py` 整目录重生成 → `--check` 逐字节一致 → 台账登记 sha256。

> **禁止**：直接手改 `data/rules/*.json`；`pending` 条目带具体数值（防"未核对却已落值"）。

## 四、合成数据设计（`tools/gen_synthetic.py`）

### 4.1 合成企业白名单

- 虚构名称：`示例<行业>（合成）有限公司`；
- 虚构统一社会信用代码：`90000000` 号段 + `SYN` 后缀（如 `90000000SYN0000001A`）；
- 禁止任何真实企业名称/产能/营业收入/台账。

### 4.2 确定性 RNG（splitmix64）

```python
MASK64 = (1 << 64) - 1
def splitmix64(state: int) -> tuple[int, int]:   # (next_state, value)
    state = (state + 0x9E3779B97F4A7C15) & MASK64
    z = state
    z = ((z ^ (z >> 30)) * 0xBF58476D1CE4E5B9) & MASK64
    z = ((z ^ (z >> 27)) * 0x94D049BB133111EB) & MASK64
    return state, z ^ (z >> 31)
```

- **禁 stdlib `random`、禁 `set` 迭代序、禁系统时钟**；固定 `seed`；
- 落盘产物**无时间戳**，两次运行逐字节一致（配守门测试）。

### 4.3 算例覆盖

| 类别 | 算例 |
|---|---|
| 三类机制 | 煤炭（按产量）/ 危险品·冶金·机械制造·电力（按营业收入超额累退）/ 建设工程（按工程造价比例） |
| **边界** | 恰好等于分段点（1000 万 / 1 亿 / 10 亿 / 50 亿 / 100 亿）；上下最小货币单位（±0.01） |
| **单位口径错配** | 台账以"万元"填报、规则包以"元"计价 → 应报 `warning`（不静默） |
| **误报对照集** | "应零命中"的干净档案（计提正确、支出全部在范围内）；"应降级"的档案（单位可显式换算 → 只报 warning） |
| **双版本对照** | 同一对象分别按 136 号与 2012 版生成两套期望值 |

### 4.4 真值语义

- 主期望：`expect.amount` 等；
- 隐含结论：`also_expect`（同一注入隐含的其余结论）；
- 评测按"全部非 pass 字段集"对账；**对账语义收成单一实现源**（`benchmark/cases.py` 供测试与基准共用）；
- **不许改真值凑引擎**；判别两种情形：① 检查器谓词不自洽 → 只改谓词；② 真值口径错误 → 引擎与真值**同源修正**；共同验收门 = `gen_synthetic.py --check` 仍通过。

## 五、M0 → M1 交接要点（写入 HANDOFF-M1）

1. **规则包初态全部 `pending` + `value: null`**——M1 的第一件事就是逐条核对落值；
2. **既定口径**（动了会打挂基准）：段边界归属 `[lower, upper)`、金额两位 `ROUND_HALF_UP`、年度锚定按日、门控分作用域、门槛随 manifest；

4. **关键命令速查**：见 HANDOFF-M1 §速查。
